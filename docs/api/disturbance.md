# Disturbance

Forest disturbance signals in L-band backscatter and coherence time series: HV step dating, local forest-ring weather references, coherence dips against an area's own history, and an experimental forward-running Disturbance Index. See the [disturbance tutorial](../tutorials/11_disturbance_detection.ipynb) for a worked example on PROVISIONAL data from Caquetá, Colombia.
